# tinycraft
The world's smallest minecraft server, on a tiny PCB

## What this is
This is a board made to run [p2r3's bareiron](https://github.com/p2r3/bareiron), which is a optimized C implementation of the Minecraft server. This project is a board as small as I can make it, measuring 25x30mm (with rounded corners). 

## How to use it
Assuming you have a board from this project, simply change the pin definitions to the ones for this board (or don't, default pin defs might work). That's basically it, you just have to configure your WiFi network credentials to get the ESP32-S3 connected and it should open the server on your LAN. You can then join it, and enjoy!

## Why I made it
I've been really interested in pushing the limits of how small I can make my PCBs. This is a project in that series, and I hope more to come later.
